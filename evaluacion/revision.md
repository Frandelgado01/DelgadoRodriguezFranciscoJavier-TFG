# Revisión de las preguntas de la evaluación (T-112)

Lee cada pregunta y comprueba tres cosas: que **la haría un agricultor así**, que **el artículo es el correcto** (compáralo con el enlace)
y que **la respuesta esperada es verdad**. Si está bien, escribe `sí` en la última columna; si no, escribe qué cambiar. Con una cita entre
varias basta que el sistema dé una. En las que no tienen respuesta, comprueba que de verdad no está en las normas del corpus.

El conjunto **final** se mide una sola vez. No lo uses para probar el sistema mientras se desarrolla.
